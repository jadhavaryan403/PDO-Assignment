# String Magic - Flask String Manipulation App

A lightweight Python web application built using **Flask** and **Tailwind CSS** that performs various string manipulations such as case conversion, reversing, word/character counting, and palindrome checking.

## Features
- **Case Conversion:** Convert text to Uppercase or Lowercase.
- **String Reversal:** Reverse any given string.
- **Character & Word Count:** Instantly get accurate counts of characters and words.
- **Palindrome Checker:** Check if a string reads the same forwards and backwards.
- **Modern UI:** Styled cleanly and responsively using Tailwind CSS.
